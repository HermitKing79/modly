**Causal diagnosis: UNKNOWN.** The cheapest supported explanation is that the model was conditioned on a flat diagnostic color square, not an object image. That is confirmed input provenance; whether it alone caused the slab is unproved. No checkpoint, sampler, latent-layout or decoder-contract mismatch was demonstrated. There is no evidence assigning the result to AMD. Historical sampling/decode PASS classifications remain unchanged: they established computation and artifact integrity, not shape quality.

Base: `4f375f979cff645f60f415c0d7c9b653c7015b0c`, branch `codex/amd-sparse-occupancy-decode`. Investigation branch: `codex/amd-sparse-slab-diagnosis`. ## Confirmed findings

1. **The input never depicted a 3D object.** The exact saved PNG/hash and all pixels match the original fixture: a 48×48 opaque square containing smooth RGB coordinate gradients on a transparent 64×64 canvas. Canonical preprocessing crops it to 46×46 RGB, then resizes to 512. The saved DINO tensor contains five class/register tokens and 1,024 patch tokens, width 1,024. All 1,029 tokens are distinct; token standard deviations span 0.99999976–1.00000012. Features are finite and spatially varying, not zero or repeated-token collapse. This does not prove their numerical equivalence to a reference backend.
2. **The slab exists in the logits, before preview export.** All 262,144 logits and the original 32,768 latent values are finite and hash-verified. Occupancy is exactly `logits > 0`: 1,606 voxels, bbox D/H/W `[0,20,31]`–`[63,43,32]`. Every D slice contains 25–26 cells; W31/W32 contain 829/777. Only the two D boundary faces are touched, with 25 cells each; other boundary faces are empty. This is an extruded narrow structure, not full-volume saturation. Permuting axes cannot turn sorted extents `[2,24,64]` into a volumetric object.
3. **The zero threshold is not a brittle near-zero cutoff.** The complete mask is identical for diagnostic thresholds −50 through +20. Maximum nonoccupied logit is −50.5594; minimum occupied logit is +36.6956; no values lie within ±1. At −100, 943 additional negative-logit voxels expand the bbox to all-axis bounds; at −150, 35,662 voxels occupy every boundary face. Neither supplies evidence for overriding the canonical zero threshold. No adjusted mask/artifact was saved or used.
4. **The latent is small but not collapsed.** Mean 0.006999, standard deviation 0.154177, range −3.08378 to +2.36127, no exact zeros; channel matrix rank eight. Channel spatial standard deviations range 0.06237–0.21871. Neighbor RMS differences D/H/W are 0.07098/0.19405/0.23445. The D smoothness agrees with the long extrusion, but a correlation cannot identify its cause. No reference latent-distribution baseline exists to declare these magnitudes invalid.
