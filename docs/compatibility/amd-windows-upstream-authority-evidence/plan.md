# Windows upstream authority bridge

Approved scope: one host-owned conditioning ticket, one nonrecursive Windows
synthetic worker, no neural or complete shape-job claim. Base `7400e8c8b72e9e0984aa8e9b33619405be17b445`.

1. Authenticate before preservation and isolate the development branch.
2. Add a private registered invocation/authority boundary; preserve legacy CPU
   observations and the disabled generated dispatcher. Freeze original context,
   distinct ticket nonce, command, sources, cancellation and resource policy.
3. Capture native membership/creation/image identities and ordered controls
   inside the runner. Bound invocations use a bootstrap-only pipe, with a saved
   diagnostic copy. Require complete natural Job settlement, verified EOF,
   closure, unchanged sources and successful receipt publication before sealing.
4. Run focused synthetic CPU contracts and independent exact-source review.
5. Once admitted, use the supported outside-sandbox non-administrator context
   for exactly one native invocation. Reject copied/worker-authored/replayed
   handles and accept only the exact pending ticket. Do not complete three stages.
6. Independently verify actual private observations and preservation, publish
   only source-safe evidence, verify GitHub and all historical heads, then stop.

Limits remain 6 GiB process and Job, 12 GiB live RAM, 2 GiB disk, a 25-second
fixture stage and 90-second outer deadline. Any native failure is preserved;
there is no retry. The capability boundary assumes a trusted host interpreter
and pinned bootstrap; it is not a sandbox against hostile same-user native code.
